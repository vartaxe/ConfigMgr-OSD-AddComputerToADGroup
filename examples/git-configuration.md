# Git configuration

For this project's maintainer, configure identity **locally in this repository**, not globally:

```powershell
git config --local user.name "Claudio Mendes"
git config --local user.email "vartaxe@outlook.com"
git config --local user.name
git config --local user.email
git var GIT_AUTHOR_IDENT
git var GIT_COMMITTER_IDENT
```

The author and committer must resolve to `Claudio Mendes <vartaxe@outlook.com>`. Public profile: [vartaxe](https://github.com/vartaxe). Project: [ConfigMgr-OSD-AddComputerToADGroup](https://github.com/vartaxe/ConfigMgr-OSD-AddComputerToADGroup).
