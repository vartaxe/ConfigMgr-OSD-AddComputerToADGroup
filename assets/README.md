# Artwork and notices

## Project banners

`banner.svg` and `banner-compact.svg` are generated by `build\Update-Banners.ps1`
from `branding.json`. The generator is identical in both OSD repositories.
Do not hand-edit the SVGs: use the [development guide](../docs/development.md).
The layout shares dimensions, typography, spacing, owner label, runtime/license
footer, and dark-mode colors. Only the project text and bare script filename differ.
